## Resumo

### **Descrição do Problema**

Programar um jogo em python no qual o utilizador e o computador escolhem um número de 1 a 10 para somar, vencendo aquele que chegar ao número 100. O jogo pode ser realizado das seguintes formas:
1. o utilizador escolhe primeiro o número (e ganha apenas se executar o jogo sem falhas);
2. o computador inicia o jogo (e assim sendo tem que ganhar obrigatoriamente).
