## Resumo

### **Descrição do Problema**

Criação de um programa que permite a manipulação de listas:
    - O utilizador pode criar uma lista com elementos à sua escolha ou pedir que o computador escolha aleatoriamente os elementos da lista.
    - Tendo uma lista, o utilizador pode realizar diversas operações como:
        - Somar todos os elementos,
        - Calcular a média dos elementos,
        - Pedir que o programa identifique o maio/menor elemento da lista,
        - Pedir que o programa analise se os elementos da lista se encontram por ordem crescente/decrescente ou não.
        - Determinar a posição de um elemento na lista.
